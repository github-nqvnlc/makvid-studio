# clip-maker [![CI](https://img.shields.io/badge/ci-passing-green)](https://example.com)

Công cụ dòng lệnh giúp biến một đoạn văn bản thành video ngắn có phụ đề.

![demo](docs/demo.gif)

## Cài đặt

```bash
npm install -g clip-maker
```

## Tính năng

- Tự chia cảnh theo câu
- Phụ đề tiếng Việt chuẩn dấu
- Xuất 9:16 và 16:9
